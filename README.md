# Simulador de Combate - POO en Python

## Descripción

Proyecto desarrollado a partir del video de BitBoss sobre Programación Orientada a Objetos en Python.

## Conceptos aplicados

- Clases
- Objetos
- Abstracción
- Encapsulación
- Herencia
- Polimorfismo

## Clases

### Personaje
Clase base del sistema.

### Guerrero
Hereda de Personaje y utiliza una espada.

### Mago
Hereda de Personaje y utiliza un libro mágico.

## Pilares de la POO

### Abstracción
Representación de personajes mediante atributos esenciales.

### Encapsulación
Los datos y métodos se encuentran agrupados en clases.

### Herencia
Guerrero y Mago heredan de Personaje.

### Polimorfismo
El método daño() se redefine en cada clase.
